# LimitRoom: сохранённый дизайн

Дата: 2026-09-21. Это визуальные макеты, не сборки приложения.

Актуальный инкремент — **нативная версия 0.3.0**: данные одной квоты по сторонам камеры, hover по всей чёлке, без выступа под камерой в закрытом состоянии. Исторический HTML v3 ниже не описывает эту новую геометрию. Контракт: [integrated notch](../superpowers/specs/2026-09-21-integrated-notch-design.md). Рендеры собственных views лежат в `build/v030-*.png`; они не подтверждают физический hover/haptics.

Пользователь утвердил композицию и структуру интерфейса, выбрал иконку **A — «Запас»** и согласовал третью версию. Для нативной реализации дополнительно запросил тактильный отклик при раскрытии, плавную анимацию и скруглённое сопряжение чёлки с панелью. [Спецификация реализации](../superpowers/specs/2026-09-21-presentation-refresh-design.md).

## Правки v3

Внизу каждого раскрытия вместо «Только на вашем Mac» отображается версия. В макете это `v0.1.0`, соответствующая установленной сборке на момент проверки; подсказка содержит номер сборки `1`. В приложении значение следует получать из метаданных текущего Bundle. Булавка меняет только собственное состояние, а не подпись версии.

В режиме возле камеры компактный индикатор продолжает вырез по ширине и цвету, без просвета или разделительной линии. Раскрытие образует одну чёрную фигуру: узкая верхняя часть объединена с камерой, широкая нижняя содержит прежние карточки и вкладки. Верхняя область камеры пассивна: в ней нет кнопок, данных или области наведения LimitRoom. Элементы управления начинаются ниже строки меню; боковые участки системного меню не закрашиваются.

Чёрная оболочка сохраняется в обеих темах, чтобы не отделяться от камеры. В режиме menu bar остаются прежние светлый и тёмный варианты. Первым в v3 открыт режим возле камеры только для просмотра изменения — режимом приложения по умолчанию остаётся menu bar.

## Проверка и ограничения

В браузере визуально проверены компактная и раскрытая формы. Цвет камеры, соединения и оболочки совпадает; ширина компактного индикатора совпадает с шириной камеры, между ними нет просвета. Версия остаётся на месте при включении булавки; закрытие сбрасывает удержание. Проверены три карточки и отсутствие интерактивных элементов в области камеры.

Показания, планы, время и графики демонстрационные. Макет ничего не читает из аккаунтов и не изменяет настройки приложения. Иконки агентов пока схематичные. HTML не доказывает работу AppKit, нативного hit-testing, анимации, Spaces, полноэкранного режима или автоскрытия меню — это проверяется отдельно при реализации.

Сессионная копия для Visual Companion находится в игнорируемом `.superpowers/`. Адрес и ключ локального сервера не входят в сохранённые артефакты.

## Нативная реализация 0.2.0

Дизайн перенесён в общие SwiftUI-карточки и AppKit-панель. В локальном `build/` сохранены рендеры собственных demo-views: `native-menu-light-en.png`, `native-menu-dark-ru.png`, `native-notch-expanded.png`, `native-notch-compact.png`, `native-notch-no-percent.png`, `native-statistics-en.png`, `native-settings-ru.png`, `native-indicator.png`. Это не снимки рабочего стола. Камера в рендере — синтетическая подложка для просмотра контура, не доказательство позиционирования на дисплее.

Версия берётся из Bundle: `v0.2.0`, build 2. Физический отклик, hover/focus и переходы Spaces проверяются отдельно: [результаты и чек-лист](../verification.md). Установка поверх существующей копии и публикация не выполнялись.
