# LimitRoom 0.5.1

## Что изменилось

- Акцентный цвет вернулся в отдельное окно настроек; выбранный раздел заметно выделен.
- В «Основных» можно выбрать интервал обновления квот: 1, 5, 30 минут или час. По умолчанию — 5 минут; выбор сохраняется между запусками.
- Открытие настроек сворачивает панель у камеры, в том числе закреплённую булавкой.
- Убрана надпись о немедленном сохранении оформления.
- При появлении новой версии над нижней строкой панели показывается заметная кнопка «Обновить LimitRoom» с номером версии. Загрузка и ошибки также подписаны явно.

## Changes

- Restored settings accent colors and highlighted the selected section.
- Added a saved allowance refresh interval: 1, 5, 30 minutes or 1 hour; the default remains 5 minutes.
- Opening Settings collapses the notch panel, including when it is pinned.
- Removed the appearance autosave caption.
- Available app updates now have a prominent, version-labelled button above the panel footer, with explicit progress and error states.

## Distribution and verification

Build 7. Universal Apple Silicon + Intel, macOS 14+. Ad-hoc signed, not Apple Developer ID signed or notarized. Sparkle verifies signed updates; it does not replace Gatekeeper requirements.

Native interaction, interval persistence after relaunch, live provider behavior and complete update installation/relaunch remain manual acceptance checks. Build and demo-render verification are not automated behavioral tests.
