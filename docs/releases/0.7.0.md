# LimitRoom 0.7.0

## English

- Quota charts use a calmer, smoothed trend with continuous visual bridges across collection gaps and reset boundaries. Dashed bridges distinguish unmeasured intervals; hover preserves exact observations.
- Added a 3-day period and made it the default. Local quota observations older than 90 days are automatically deleted when history is read or recorded, including after reopening the app.
- A shared Tokens chart compares daily Codex and Cursor activity when their sources provide it. Missing days remain unknown; Claude's current connection does not provide account token history.
- Subscription details show extra reset counts only when the source provides a fresh value. Codex can report remaining resets. Unknown counts, including used-reset totals unavailable from current sources, stay hidden.
- Opening settings, full history, or another window dismisses the menu-bar/notch panel and clears its temporary pin.
- More realistic synthetic activity and an updated statistics screenshot.
- Local builds are named **LimitRoom Dev** and never run the release updater. Successful local packaging keeps one current Dev app and removes obsolete project build copies.
- One manual Release workflow takes current `main` and a version number; it runs checks, assigns the next build number, and publishes signed updates. Separate push/PR builds were removed.

Build 11. Universal app for Apple Silicon and Intel, macOS 14+. Current builds are ad-hoc signed, not Apple Developer ID signed or notarized; see the [first-launch guide](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation). Cursor's personal dashboard API can change; live provider connections and native window interactions require separate acceptance checks.

## Русский

- Графики квот стали спокойнее и плавнее. Паузы сбора данных и границы сбросов соединены пунктиром, который не выдаётся за измерения; при наведении доступны точные показания.
- Добавлен период 3 дня и выбран по умолчанию. Локальные показания старше 90 дней автоматически удаляются при чтении и записи истории, в том числе после повторного запуска приложения.
- Общий график «Токены» сравнивает дневную активность Codex и Cursor, если источники её предоставляют. Пропущенные дни не считаются нулевыми; текущее подключение Claude не передаёт историю токенов аккаунта.
- В подробностях подписки показываются только известные и свежие счётчики дополнительных сбросов. Codex может сообщать остаток. Неизвестные значения, включая недоступное в текущих источниках общее число использованных сбросов, скрыты.
- Открытие настроек, полной истории и других окон закрывает панель у чёлки или строки меню и снимает временный пин.
- Демо-статистика стала реалистичнее; обновлён скриншот графика.
- Локальные сборки называются **LimitRoom Dev** и не используют обновления релизной версии. После успешной сборки остаётся одно актуальное Dev-приложение; устаревшие копии в папке сборки проекта удаляются.
- Один ручной workflow Release берёт актуальный `main` и указанную версию: выполняет проверки, назначает следующий номер сборки и публикует подписанное обновление. Отдельные сборки по push/PR удалены.

Сборка 11. Универсальное приложение для Apple Silicon и Intel, macOS 14+. Сборка имеет ad-hoc-подпись, но пока без Apple Developer ID и нотариализации; см. [инструкцию первого запуска](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation). Приватный API Cursor может меняться; реальные подключения к агентам и нативные взаимодействия с окнами требуют отдельной проверки.
