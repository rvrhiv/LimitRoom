# LimitRoom 0.8.0

## English

- Only the selected agent refreshes in the background. Opening the menu-bar or notch panel refreshes all connected agents; while the panel stays open, the configured interval applies to all of them.
- Cursor's alternative web session no longer loads at startup when Cursor is not selected. Its hidden dashboard is unloaded when it leaves the refresh scope.
- Stale readings are easier to recognize: quota values, rings, progress bars, and reset information turn gray alongside the clock indicator. Previous values remain visible without being presented as fresh measurements.
- Subscription labels preserve the plan reported by each provider. Codex distinguishes Pro and Pro Lite when reported, without guessing a usage multiplier that its interface does not expose.
- Local builds display a separate `BASE-dev.N` version in the panel and settings. Official releases display the release version only, without a Dev suffix. Development build counters are local and independent of release numbering.

Universal app for Apple Silicon and Intel, macOS 14+. Current builds are ad-hoc signed, not Apple Developer ID signed or notarized; see the [first-launch guide](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation).

## Русский

- В фоне обновляется только выбранный агент. Открытие панели у чёлки или в строке меню обновляет всех подключённых агентов; пока панель открыта, заданный интервал действует для всех.
- Альтернативная веб-сессия Cursor больше не загружается при запуске, если Cursor не выбран. Скрытая страница выгружается, когда Cursor выходит из области обновления.
- Устаревшие показания стали заметнее: значения квот, кольца, полосы прогресса и время сброса становятся серыми рядом со значком часов. Предыдущие значения остаются видимыми, но не выдаются за свежие измерения.
- Названия подписок сохраняют план, сообщённый источником. Для Codex различаются Pro и Pro Lite, если источник их сообщает, без догадок о недоступном множителе лимитов.
- Локальные сборки показывают отдельную версию `BASE-dev.N` в панели и настройках. Официальные релизы показывают только версию релиза, без Dev-суффикса. Счётчики Dev-сборок хранятся локально и не влияют на нумерацию релизов.

Универсальное приложение для Apple Silicon и Intel, macOS 14+. Сборка имеет ad-hoc-подпись, но пока без Apple Developer ID и нотариализации; см. [инструкцию первого запуска](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation).
