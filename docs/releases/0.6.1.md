# LimitRoom 0.6.1

## English

- Fixed uneven outer spacing between the quota and reset indicators beside the camera. Both visible wings use the same configured width and mirrored content alignment.
- Kept text clear of the expanded notch's rounded shoulders while preserving the available content width, including narrow settings and swapped sides.

Build 9. Universal app for Apple Silicon and Intel, macOS 14+. Current builds are ad-hoc signed, not Apple Developer ID signed or notarized; see the [first-launch guide](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation).

## Русский

- Исправлены неодинаковые внешние отступы у квоты и времени сброса рядом с камерой. Обе видимые стороны используют одну настроенную ширину и зеркальное выравнивание содержимого.
- Текст не заходит на скругления раскрытой чёлки. Доступная ширина содержимого сохранена, в том числе при узкой настройке и перестановке сторон.

Сборка 9. Универсальное приложение для Apple Silicon и Intel, macOS 14+. Сборка имеет ad-hoc-подпись, но пока без Apple Developer ID и нотариализации; см. [инструкцию первого запуска](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation).
