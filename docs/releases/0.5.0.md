# LimitRoom 0.5.0

- Official Cursor cube mark instead of a generic pointer.
- Clear settings sections: Appearance, Agents, Notifications, General and Updates.
- Shared live previews with focused controls for each side of the camera.
- Stable notch header layout during opening; dashboard content no longer displaces the quota text.
- A compact update button and signed Sparkle updates from GitHub Releases. Installation requires a click and relaunches the app.

macOS 14 or later; universal Apple Silicon and Intel binary. This early build is ad-hoc signed, not Apple Developer ID signed or notarized. macOS may block first launch; do not disable Gatekeeper. See Apple's guidance for opening software from an unidentified developer and only proceed if you trust this release.

Install 0.5.0 manually once: older builds do not contain an updater. Quit the old LimitRoom before replacing it in Applications. Existing preferences and local history remain in Application Support/UserDefaults. A working signed release channel is required for subsequent updates.

The widget is not installed in this build. Live provider/account behavior, hardware haptics, Spaces and full update replacement remain manual acceptance items. Builds and signature validation are not automated behavioral tests.
