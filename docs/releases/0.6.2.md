# LimitRoom 0.6.2

## English

- Replaced Claude Code's generic asterisk with the official Claude Spark across agent cards and indicators.
- Smoothed quota-history lines while preserving observed values, gaps, and cycle boundaries. Codex token statistics remain bars.
- Removed Cursor's experimental labels from settings, connection messages, source names, and documentation. Connection permissions and private-API compatibility warnings are unchanged.

Build 10. Universal app for Apple Silicon and Intel, macOS 14+. Current builds are ad-hoc signed, not Apple Developer ID signed or notarized; see the [first-launch guide](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation).

## Русский

- Системная звёздочка Claude Code заменена официальным знаком Claude Spark в карточках и индикаторах.
- Линии истории квот стали плавнее. Реальные показания, разрывы и границы циклов сохранены; статистика токенов Codex осталась столбчатой.
- Убраны пометки «экспериментально» у Cursor в настройках, сообщениях подключения, названиях источников и документации. Разрешения на подключение и предупреждения о совместимости приватного API сохранены.

Сборка 10. Универсальное приложение для Apple Silicon и Intel, macOS 14+. Сборка имеет ad-hoc-подпись, но пока без Apple Developer ID и нотариализации; см. [инструкцию первого запуска](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation).
