# LimitRoom 0.6.0

## What's new

- Quota history now shows **remaining allowance from 0 to 100%**, replacing the confusing percentage-points-per-day graph. Choose a window for each agent independently of the pinned indicator.
- Hover for actual readings and timestamps. New-cycle markers and gaps distinguish resets and missing data from consumption.
- A separate **Codex tokens** view shows daily account activity and a lifetime total when Codex provides them. Missing days remain unknown, not zero; tokens are never converted into quota percentages or prices.
- Refined the compact statistics panel, improved long-history rendering, and refreshed the English/Russian guides and screenshot.

## Что изменилось

- Вместо графика процентных пунктов в сутки теперь показывается **остаток квоты от 0 до 100%**. Окно каждого агента выбирается независимо от индикатора.
- При наведении видны реальные измерения и время. Отметки новых циклов и разрывы отделяют сбросы и отсутствие данных от расхода.
- В отдельном режиме **«Токены Codex»** — дневная активность аккаунта и общий счётчик, если Codex их предоставляет. Пропуски не считаются нулём; токены не переводятся в проценты квоты или стоимость.
- Доработаны компактная панель статистики и отрисовка длинной истории. Обновлены документация на двух языках и скриншот.

## Availability and installation

Build 8. Universal Apple Silicon + Intel, macOS 14+. Codex token statistics require a supporting Codex version and account. They are account-wide, not limited to this Mac, and remain memory-only in LimitRoom. Token statistics for Claude and Cursor are not included in this release.

The app is ad-hoc signed, **not Apple Developer ID signed or notarized**. Sparkle verifies signed updates but does not replace Apple's first-install checks. If macOS blocks the first launch, follow the [installation guide](https://github.com/rvrhiv/LimitRoom/blob/main/docs/usage.md#installation); keep Gatekeeper and quarantine enabled.

Verification covers builds, source checks, code review, and synthetic English/Russian previews. Live Codex token readings, native hover/VoiceOver interaction, and the complete update-installation/relaunch path still need manual acceptance. No new automated tests were added without assigned test-case IDs.
