LimitRoom — нативное macOS-приложение для отслеживания квот **Codex, Claude Code и Cursor**. Закрепите нужную квоту в строке меню или разместите её рядом с чёлкой MacBook. Откройте одну панель, чтобы увидеть остальные.

## Немного больше запаса

- **Нужная квота с одного взгляда.** Иконка агента, кольцо остатка и процент. Выберите, какие элементы показывать, и закрепите окно квоты прямо в карточке агента.
- **Два компактных режима.** Нажмите на индикатор в строке меню или наведите указатель на чёлку, чтобы открыть все три карточки. Булавка удержит панель открытой.
- **Понятный темп расхода.** Локальная история за 90 дней, сравнение наблюдаемых изменений квот и экспорт в CSV или JSON. Графики показывают изменение процентов, а не токены или стоимость.
- **Как часть macOS.** Живой предпросмотр, светлое и тёмное оформление, отключаемый тактильный отклик, поддержка уменьшения движения. Русский или английский выбирается по языку системы.
- **Всё под вашим контролем.** Обновление квот раз в 1, 5, 30 или 60 минут; включайте уведомления о низком остатке и выбирайте, запускать ли приложение при входе в систему. Подписанные обновления приложения устанавливаются только по вашему действию.

## Начало работы

1. Скачайте ZIP из [последнего релиза](https://github.com/rvrhiv/LimitRoom/releases/latest).
2. Завершите старый экземпляр LimitRoom, распакуйте архив и перенесите **LimitRoom.app** в **«Программы»**.
3. Откройте приложение, подключите агентов в **«Настройки → Агенты»** и выберите квоту для индикатора.

Требуется **macOS 14 или новее**. Универсальные сборки включают **Apple Silicon и Intel**. Режим у камеры требует поддерживаемого встроенного экрана с вырезом; на других экранах используется строка меню.

> Ранние сборки подписаны ad-hoc, без Apple Developer ID и notarization. macOS может заблокировать первый запуск. Sparkle проверяет обновления приложения, но не заменяет проверку безопасности Apple при первой установке. Подробнее — в [инструкции по установке](docs/usage.md#installation).

## Все агенты рядом

| Агент | Подключение | Что доступно |
| --- | --- | --- |
| **Codex** | Установленный Codex CLI с существующим входом в ChatGPT | Окна квот подписки, которые сообщает Codex; нужен CLI с поддержкой App Server. |
| **Claude Code** | Явно подключаемый и обратимо настраиваемый помощник для строки статуса | Квоты из активной сессии Claude Code; доступность зависит от версии и подписки. |
| **Cursor** | Вход установленного Cursor с вашего разрешения | **Экспериментальное** чтение личной квоты через приватные интерфейсы dashboard; совместимость может меняться. Есть отдельный вход через встроенный браузер. |

Один активный аккаунт на агента. Сведения о подписке и сбросе отображаются, если их сообщает источник. Отсутствующие или устаревшие данные явно отмечаются, а не заменяются выдуманным остатком. [Подключение агентов →](docs/usage.md#connect-your-agents)

## Данные остаются у вас

Без аккаунта LimitRoom, собственного сервера и телеметрии. История хранится на вашем Mac. Приложение не читает переписки и не импортирует cookies браузеров. Сетевые запросы идут к сервисам подключённых агентов и на GitHub за обновлениями — приложение не полностью офлайн. [Данные и приватность →](docs/usage.md#data-and-privacy)

## Сборка и участие

Понадобятся полный Xcode и Swift 6:

```sh
git clone https://github.com/rvrhiv/LimitRoom.git
cd LimitRoom
bash Scripts/build-app.sh Release
open build/LimitRoom.app --args --demo
```

Демо-режим показывает интерфейс без чтения аккаунтов агентов и записи личной статистики. Скрипт сборки не заменяет установленное приложение.
