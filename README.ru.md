LimitRoom — нативное macOS-приложение для отслеживания квот **Codex, Claude Code и Cursor**. Закрепите нужную квоту в строке меню или разместите её рядом с чёлкой MacBook. Откройте одну панель, чтобы увидеть остальные.

## Немного больше запаса

- **Нужная квота с одного взгляда.** Иконка агента, кольцо остатка и процент. Выберите, какие элементы показывать, и закрепите окно квоты прямо в карточке агента.
- **Два компактных режима.** Нажмите на индикатор в строке меню или наведите указатель на чёлку, чтобы открыть все три карточки. Булавка удержит панель открытой.
- **Понятная статистика.** Сравнивайте остаток квот на плавном графике от 0 до 100%, выбирайте 1, 3, 7, 30 или 90 дней и экспортируйте локальную историю в CSV или JSON. Общий график токенов сравнивает дневную активность поддерживаемых агентов отдельно от квоты и стоимости.
- **Как часть macOS.** Живой предпросмотр, светлое и тёмное оформление, отключаемый тактильный отклик, поддержка уменьшения движения. Русский или английский выбирается по языку системы.
- **Всё под вашим контролем.** Обновление квот раз в 1, 5, 30 или 60 минут; включайте уведомления о низком остатке и выбирайте, запускать ли приложение при входе в систему. Подписанные обновления приложения устанавливаются только по вашему действию.

## Начало работы

1. Скачайте ZIP из [последнего релиза](https://github.com/rvrhiv/LimitRoom/releases/latest).
2. Завершите старый экземпляр LimitRoom, распакуйте архив и перенесите **LimitRoom.app** в **«Программы»**.
3. Откройте приложение, подключите агентов в **«Настройки → Агенты»** и выберите квоту для индикатора.

Требуется **macOS 14 или новее**. Универсальные сборки включают **Apple Silicon и Intel**. Режим у камеры требует поддерживаемого встроенного экрана с вырезом; на других экранах используется строка меню.

### Первый запуск на macOS

Текущие сборки подписаны локально (ad-hoc), без Apple Developer ID и нотариализации. macOS может сообщить, что не удалось проверить LimitRoom или подтвердить отсутствие вредоносного ПО.

Если вы скачали приложение из релизов этого репозитория и доверяете сборке:

1. Попробуйте открыть **LimitRoom.app** из **«Программ»**, затем закройте предупреждение, не перемещая приложение в Корзину.
2. Перейдите в **«Системные настройки → Конфиденциальность и безопасность»**, прокрутите вниз и нажмите **«Всё равно открыть»** для LimitRoom.
3. Подтвердите запуск кнопкой **«Открыть»**; при запросе подтвердите действие паролем или Touch ID.

Это разрешает запуск конкретного приложения, не отключая Gatekeeper. Не обходите предупреждения об обнаруженном вредоносном ПО или повреждении приложения. Подробнее — в [инструкции Apple](https://support.apple.com/ru-ru/102445) и [руководстве по установке](docs/usage.md#installation).

## Все агенты рядом

| Агент | Подключение | Что доступно |
| --- | --- | --- |
| **Codex** | Установленный Codex CLI с существующим входом в ChatGPT | Окна квот подписки и статистика токенов аккаунта, если она доступна; нужен CLI с поддержкой App Server. |
| **Claude Code** | Явно подключаемый и обратимо настраиваемый помощник для строки статуса | Квоты из активной сессии Claude Code; доступность зависит от версии и подписки. |
| **Cursor** | Вход установленного Cursor с вашего разрешения | Личная квота и история токенов, если она доступна, через приватные интерфейсы dashboard; совместимость может меняться. Есть отдельный вход через встроенный браузер. |

Один активный аккаунт на агента. Сведения о подписке, времени сброса и количестве дополнительных сбросов отображаются, если их сообщает источник; неизвестные счётчики сбросов скрыты. Отсутствующие или устаревшие показания квот не заменяются выдуманным остатком. [Подключение агентов →](docs/usage.md#connect-your-agents)

## Данные остаются у вас

Без аккаунта LimitRoom, собственного сервера и телеметрии. История квот хранится на вашем Mac; история токенов приходит от агентов и не кешируется на диск. Приложение не читает переписки и не импортирует cookies браузеров. Сетевые запросы идут к сервисам подключённых агентов и на GitHub за обновлениями — приложение не полностью офлайн. [Данные и приватность →](docs/usage.md#data-and-privacy)

## Сборка и участие

Понадобятся полный Xcode и Swift 6:

```sh
git clone https://github.com/rvrhiv/LimitRoom.git
cd LimitRoom
bash Scripts/build-app.sh Release
open 'build/LimitRoom Dev.app' --args --demo
```

Локальные сборки называются **LimitRoom Dev** и не получают обновления из релизов. Демо-режим показывает интерфейс без чтения аккаунтов агентов и записи личной статистики. Скрипт сборки не заменяет установленное приложение.
